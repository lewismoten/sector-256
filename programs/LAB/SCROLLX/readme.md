# SCROLLX

`SCROLLX` is a tiny Commodore 64 VIC-II experiment. Press a key to cycle the horizontal fine-scroll offset from zero through seven; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `SCROLLX` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
