# CHAOS

The triangle chaos game on a centered 256×200 high-resolution Commodore 64
bitmap. Starting from the middle, the program repeatedly chooses one of three
vertices with equal probability, moves halfway toward it, and plots the result.
Thousands of random choices reveal a deterministic Sierpinski triangle.

The program adds 64 points per video frame. Press SPACE to clear the bitmap and
start again; RUN/STOP returns to the LAB category.
