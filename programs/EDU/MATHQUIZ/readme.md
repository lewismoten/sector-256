# MATHQUIZ

`MATHQUIZ` is a tiny Commodore 64 arithmetic practice aid. Press a key to move through a rotating set of mixed operation facts; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `MATHQUIZ` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
