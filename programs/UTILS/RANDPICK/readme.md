# RANDPICK

`RANDPICK` is a tiny Commodore 64 random choice utility. It chooses a value from one through six each time a key is pressed; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `RANDPICK` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
