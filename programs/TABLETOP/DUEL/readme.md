# DUEL

DUEL is a two-player draw game. Player 1 fires with `A`; player 2 fires with
`L`. Wait for the randomized DRAW signal, then shoot first to win. Shooting
before DRAW gives the round to the other gunslinger.

Press RETURN after a result for a new duel. RUN/STOP returns to the Sector 256
launcher.

The game is stored in a single 256-byte disk block.
