# COWBULL

COWBULL is a compact four-digit deduction game for the Commodore 64. The
computer selects four digits from 0 through 7. Type four digits to make a
guess; **B** counts digits in the correct position and **C** counts matching
digits in the wrong position.

The secret can contain repeated digits, so the displayed C count is based on
all digit matches after exact-position matches are removed. Press any key to
try another guess against the same secret, or RETURN to generate a new secret.
RUN/STOP returns to the Sector 256 launcher.

The game is stored in a single 256-byte disk block.
