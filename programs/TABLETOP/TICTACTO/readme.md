# TICTACTO

`TICTACTO` is a compact Commodore 64 two-player tic-tac-toe game. Take turns choosing squares to make a horizontal, vertical, or diagonal line; use RUN/STOP to return to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `TICTACTO` in the Sector 256 D64 image. Its stored payload stays within the 256-byte Sector 256 limit.
