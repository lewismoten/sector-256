# DODGE

DODGE is a one-screen survival game for the Commodore 64. Move the runner
with **A** and **D** to avoid blocks falling from random columns. Every block
that reaches the ground without hitting you adds one point to the score.

After a collision, press RETURN to restart. RUN/STOP returns to the Sector
256 launcher. The game updates once per video frame.

The game is stored in a single 256-byte disk block.
