# ZAP

`ZAP` is a tiny Commodore 64 target game. A new alien target appears at a random horizontal position each time a key is pressed. Press RUN/STOP to return to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `ZAP` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
