# CATCHER

CATCHER is a small reflex game for the Commodore 64. Move the two-cell basket
with **A** and **D** and catch the falling `*` stars. Each catch adds to the
score; three misses end the game.

Press RETURN after a game to restart. RUN/STOP returns to the Sector 256
launcher. Stars begin in a random column and fall one text row per video frame.

The game is stored in a single 256-byte disk block.
