# CRAPS

Press SPACE to roll two dice. On the first roll, 7 or 11 wins and 2, 3, or 12
loses. Any other total becomes the point. Continue rolling until you repeat the
point and win, or roll a 7 and lose.

Press RETURN after a result to start another game. RUN/STOP returns to the
Sector 256 launcher.

The game is stored in a single 256-byte disk block.
