# BELLS

`BELLS` is a tiny Commodore 64 SID sound experiment. Press a key to alternate two bright bell-like pitches; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `BELLS` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
