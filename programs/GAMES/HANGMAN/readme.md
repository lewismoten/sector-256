# HANGMAN

`HANGMAN` is a compact Commodore 64 word-guessing game. Identify the letters in a six-letter word before six incorrect guesses complete the drawing; use RUN/STOP to return to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `HANGMAN` in the Sector 256 D64 image. Its stored payload stays within the 256-byte Sector 256 limit.
