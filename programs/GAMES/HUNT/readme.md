# HUNT

HUNT hides treasure at one of eight positions. Type a number from `1` through
`8`. A WARM hint means the treasure is within two positions; COLD means it is
farther away. Find the exact position to win.

Press RETURN after finding the treasure for a new hidden location. RUN/STOP
returns to the Sector 256 launcher.

The game is stored in a single 256-byte disk block.
