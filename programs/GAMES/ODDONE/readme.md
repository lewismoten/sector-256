# ODDONE

`ODDONE` is a compact Commodore 64 visual challenge: spot the one `B` hidden among sixteen `A` characters. Press a key to deal a new arrangement, or press RUN/STOP to return to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `ODDONE` in the Sector 256 D64 image. The stored payload remains under 256 bytes.
