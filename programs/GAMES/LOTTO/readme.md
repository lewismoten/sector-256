# LOTTO

Pick six digits from `1` through `9`. LOTTO draws six random balls and counts
each drawn value that appears in your picks. Repeated picks are allowed, which
can improve the chance of matching a particular ball but reduces the range of
your ticket.

Press RETURN after the result to begin another draw. RUN/STOP returns to the
Sector 256 launcher.

The game is stored in a single 256-byte disk block.
