# FISHING

FISHING is a timing game for the Commodore 64. Press SPACE to cast, wait for
the fish to bite, then press SPACE again to land it. Striking before the
“BITE!” message loses that cast; each successful catch increases the total.

The bite delay is randomized on every cast. RUN/STOP returns to the Sector 256
launcher.

The game is stored in a single 256-byte disk block.
