# CHICKEN

CHICKEN is a two-player reaction game. Player 1 uses `A`; player 2 uses `L`.
Wait for the random GO signal. Once it appears, the first driver to press their
key swerves and loses. A key pressed before GO makes both drivers lose.

Press RETURN after a result for another round. RUN/STOP returns to the Sector
256 launcher.

The game is stored in a single 256-byte disk block.
