# BALLOON

BALLOON is a one-button push-your-luck game for the Commodore 64. Press
SPACE to pump the balloon: each safe breath adds a point, but also raises the
chance that the next breath will pop it. The eighth pump always bursts.

After a pop, press RETURN for another round. RUN/STOP returns to the Sector
256 launcher. The program uses a changing launcher random byte, so the safe
number of pumps varies from round to round.

The game is stored in a single 256-byte disk block.
