# HOTPOT

HOTPOT is a pass-the-keyboard game. Press any key to pass the hot pot to the
next player. Its fuse has a hidden random length, and the player who presses
the key when it reaches zero loses the round.

Press RETURN after the result to start a new round. RUN/STOP returns to the
Sector 256 launcher.

The game is stored in a single 256-byte disk block.
