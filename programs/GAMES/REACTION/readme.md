# REACTION

`REACTION` is a one-key Commodore 64 timing game. Wait for the random delay to end and the GO prompt to appear, then press a key. After the result screen, press a key to play again. RUN/STOP returns to the Sector 256 launcher.

## Build

From the repository root, run `python3 scripts/build.py` to assemble the program and include it in the Sector 256 D64 image. The stored payload is kept within the project's 256-byte limit.
