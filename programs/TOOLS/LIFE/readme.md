# LIFE

A compact implementation of Conway's Game of Life for the Commodore 64. Open
TOOLS, select LIFE, and press RETURN. The program seeds a random 38×23 field and
then applies Conway's standard survival and birth rules continuously.

Press SPACE to clear and randomize the field. RUN/STOP returns to the launcher.
Each living cell is a light green character block on a black background. The
next generation is calculated off screen and copied into view all at once.
