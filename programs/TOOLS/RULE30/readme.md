# RULE30

The Rule 30 elementary cellular automaton on a centered 256×200 high-resolution
Commodore 64 bitmap. A single cell seeds the first row. Each video frame applies
Rule 30 to all 256 cells and draws the next generation one scanline lower.

The horizontal field wraps at its edges. After 200 generations the completed
pattern remains on screen. Press SPACE to clear and restart it; RUN/STOP returns
to the TOOLS category.
