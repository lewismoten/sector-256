# ARCHERY

Use `A` and `D` to set an aim position from 1 through 8, then press SPACE to
fire. The target and a rightward wind gust are randomized for every round. A
`.` means calm air; `>` means the arrow moves one position to the right.

Press RETURN after a hit or miss to start another round. RUN/STOP returns to
the Sector 256 launcher.

The game is stored in a single 256-byte disk block.
