# DICE

DICE is a two-die roller for the Commodore 64. Press SPACE to start a brief
animated tumble; the dice settle after twelve video frames. Press SPACE again
at any time to begin another roll.

RUN/STOP returns to the Sector 256 launcher. The two values come from the
launcher’s changing random-byte service and are shown as digits from 1 to 6.

The program is stored in a single 256-byte disk block.
