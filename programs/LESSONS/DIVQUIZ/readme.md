# DIVQUIZ

`DIVQUIZ` is a tiny Commodore 64 division practice aid. Press a key to move through a rotating set of division facts; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `DIVQUIZ` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
