# MAPGRID

`MAPGRID` is a tiny Commodore 64 coordinate-reading exercise. It displays a lettered grid and cycles through position prompts with each key press. RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `MAPGRID` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
