# SPINTOP

`SPINTOP` is a tiny Commodore 64 character-art toy. Press any key to advance through four frames of a spinning top; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `SPINTOP` in the Sector 256 D64 image. The stored payload remains under 256 bytes.
