# GUESSNUM

GUESSNUM picks a hidden number from 00 through 99. Type a two-digit guess and
use the HIGH and LOW hints to narrow the range. A correct guess prints WIN;
press RETURN to start a new number.

The launcher random-byte service chooses the target. RUN/STOP returns to the
Sector 256 launcher.

The game is stored in a single 256-byte disk block.
