# ECHOSEQ

ECHOSEQ displays a random sequence made from `A` through `D`, then asks you to
repeat it. Each successful round adds one more signal. Repeat six signals in a
row to win; one incorrect key ends the game.

Press RETURN after a result for a fresh sequence. RUN/STOP returns to the
Sector 256 launcher.

The game is stored in a single 256-byte disk block.
