# HEXFLOW

`HEXFLOW` is a tiny Commodore 64 character-mode data-stream demo. Press a key to create a new random hexadecimal field; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `HEXFLOW` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
