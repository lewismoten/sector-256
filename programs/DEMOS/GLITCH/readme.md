# GLITCH

`GLITCH` is a tiny Commodore 64 character-mode corruption demo. Press a key to generate a fresh randomized PETSCII-like glitch field; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `GLITCH` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
