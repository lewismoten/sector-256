# COLORCYC

`COLORCYC` is a tiny Commodore 64 VIC-II color experiment. Press a key to step the background through the sixteen-color palette; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `COLORCYC` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
