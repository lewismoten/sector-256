# SUNSET

`SUNSET` is a tiny Commodore 64 character-art sunset demo. Press a key to alternate the sun-and-waves frames; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `SUNSET` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
