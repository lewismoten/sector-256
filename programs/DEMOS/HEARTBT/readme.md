# HEARTBT

`HEARTBT` is a tiny Commodore 64 character-art heartbeat demo. Press any key to move between two pulse frames while a brief SID tone sounds; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `HEARTBT` in the Sector 256 D64 image. Its stored payload remains below 256 bytes.
