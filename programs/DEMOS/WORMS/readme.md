# WORMS

`WORMS` is a tiny Commodore 64 character-mode crawling-field demo. Press a key to generate a new random worm-segment pattern; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `WORMS` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
