# PHONERNG

`PHONERNG` is a tiny Commodore 64 SID sound experiment. Press a key to alternate the two tones of a telephone-like ring; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `PHONERNG` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
