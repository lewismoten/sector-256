# NEON

`NEON` is a tiny Commodore 64 character-mode sign demo. Press a key to switch between bright and dim neon frames; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `NEON` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
