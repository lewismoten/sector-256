# COINSND

`COINSND` is a tiny Commodore 64 SID sound experiment. Press a key to alternate its arcade-style coin chimes; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `COINSND` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
