# KLAXON

`KLAXON` is a compact SID sound experiment for the Commodore 64. Press a key to move between the high and low sawtooth tones; RUN/STOP returns to the Sector 256 launcher and closes the voice gate.

## Build

Run `python3 scripts/build.py` from the repository root to assemble `KLAXON` and package it in the Sector 256 D64 image. The stored payload remains within 256 bytes.
