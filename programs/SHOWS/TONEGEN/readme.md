# TONEGEN

`TONEGEN` is a tiny Commodore 64 SID tone generator. Press a key to select the next preset pitch; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `TONEGEN` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
