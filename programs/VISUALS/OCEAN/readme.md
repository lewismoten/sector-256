# OCEAN

`OCEAN` is a tiny Commodore 64 character-mode wave demo. Press a key to advance between two rolling ocean scenes; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `OCEAN` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
