# SCANNER

`SCANNER` is a tiny Commodore 64 character-mode sweep demo. Press a key to advance the bright scanner marker across the display; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `SCANNER` in the Sector 256 D64 image. Its stored payload stays below 256 bytes.
