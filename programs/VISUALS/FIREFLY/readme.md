# FIREFLY

`FIREFLY` is a tiny Commodore 64 character-mode night-light demo. Press a key to scatter a new random field of firefly lights; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `FIREFLY` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
