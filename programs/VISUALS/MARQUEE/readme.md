# MARQUEE

`MARQUEE` is a tiny Commodore 64 character-mode light display. Each key press advances the bright marker around the sign. Press RUN/STOP at any time to return to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package the program in the Sector 256 D64 image. The program's stored payload remains under 256 bytes.
