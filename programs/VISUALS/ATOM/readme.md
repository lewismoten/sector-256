# ATOM

A compact Commodore 64 character-mode atom sketch. Press any key to advance the electron through its orbit; press RUN/STOP to return to the Sector 256 launcher.

The assembled payload stays within Sector 256's 256-byte limit.

## Build

From the repository root, run `python3 scripts/build.py`. The resulting program is packaged in the Sector 256 D64 image.
