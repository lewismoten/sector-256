# TRUCHET

`TRUCHET` is a tiny Commodore 64 character-mode texture demo. Press a key to generate a new random field of diagonal tile marks; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `TRUCHET` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
