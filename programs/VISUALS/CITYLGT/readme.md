# CITYLGT

`CITYLGT` is a tiny character-mode city-lights demo for the Commodore 64. Each key press redraws the skyline's windows with a new random pattern. Press RUN/STOP to return to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package the program in the Sector 256 D64 image. Its stored payload is limited to 256 bytes.
