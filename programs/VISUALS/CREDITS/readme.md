# CREDITS

`CREDITS` is a compact Commodore 64 character-mode credits roll. Press a key to alternate the two pages, or press RUN/STOP to return to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `CREDITS` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
