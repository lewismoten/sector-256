# RAINDROP

`RAINDROP` is a compact real-time Commodore 64 visual. A single rain streak falls, lands, splashes, and starts from a new column. RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `RAINDROP`. Its stored payload stays within 256 bytes.
