# FLOWERS

`FLOWERS` is a tiny Commodore 64 character-mode flower toy. Press a key to scatter a fresh randomized flower field; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `FLOWERS` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
