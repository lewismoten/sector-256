# POPCORN

`POPCORN` is a tiny Commodore 64 character-mode toy. Press a key to pop a fresh randomized field of kernels; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `POPCORN` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
