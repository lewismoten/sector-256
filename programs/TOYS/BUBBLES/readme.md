# BUBBLES

`BUBBLES` is a tiny Commodore 64 character-mode toy that scatters a new random field of bubble shapes whenever a key is pressed. RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `BUBBLES` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
