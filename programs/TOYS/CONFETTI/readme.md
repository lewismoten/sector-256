# CONFETTI

`CONFETTI` is a tiny Commodore 64 character-mode toy that scatters a fresh burst of random PETSCII marks whenever a key is pressed. Use RUN/STOP to return to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` in the repository root to assemble and package `CONFETTI` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
