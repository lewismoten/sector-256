# DIVISORS

`DIVISORS` is a compact Commodore 64 math reference. Press a key to rotate through worked lists of the positive divisors of several small numbers; RUN/STOP returns to the Sector 256 launcher.

## Build

Run `python3 scripts/build.py` from the repository root to assemble and package `DIVISORS` in the Sector 256 D64 image. Its stored payload stays within 256 bytes.
